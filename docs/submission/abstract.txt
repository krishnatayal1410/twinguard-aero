TwinGuard Aero is a mission-aware digital-twin proof-of-concept for aero-piston engines in MALE UAVs, developed for SIH26054. It connects synchronized engine telemetry to explainable health assessment and an interactive evaluation of proposed mission profiles.

The system compares observed measurements with a generic operating-condition-aware healthy reference. Residuals, temporal trends and correlated signals support subsystem health assessment and probable-fault hypotheses. Sensor Trust is evaluated separately so an isolated inconsistent measurement can be distinguished from corroborated physical degradation. Operators can inspect the evidence behind the assessment instead of receiving an unexplained alert.

Mission Lab combines current condition, simulation-derived remaining useful life and a selected duration, altitude, ambient temperature, throttle and mission type. It compares the same profile before and after degradation and independently rescores a lower-stress alternative. Data freshness and quality determine whether the state is eligible for analysis; insufficient live evidence produces DATA HOLD. An Evaluation Center captures healthy/fault observations and exports source-labeled evidence with an integrity checksum. Mission recording, replay and offline labeled-recording evaluation support engineering review.

The implemented architecture includes a React/TypeScript operator interface, interactive aero-piston visualization, a Python/FastAPI backend, authenticated APIs, persistent local storage and progressive synthetic fault scenarios. An optional synthetic ML pipeline uses Isolation Forest and XGBoost, with explicit model compatibility and provenance checks. HTTP ingestion is implemented, with MQTT and configurable CAN/DBC integration paths. The hosted demo is clearly labeled as a browser-based synthetic demonstration; the local/Docker deployment runs the backend workflow.

The current prototype demonstrates end-to-end software behavior and synthetic scenario consistency. Its healthy-reference equations, diagnostic scores, RUL and mission-risk assumptions require engine-specific calibration. The mission feasibility index is not a probability of mission success, and no real-flight accuracy or airworthiness claim is made.

The next validation stage uses authorized test-rig telemetry, independent fault labels and held-out operating conditions to measure false alarms, detection lead time, diagnostic performance and hardware resource use. TwinGuard's contribution is a traceable connection between measurement trust, engine-condition evidence and mission-profile consequences, with a practical route toward engine-specific validation.
