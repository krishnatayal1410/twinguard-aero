# Validation
Physics: MAE/MAPE/R² where appropriate.
Anomaly: precision, recall, ROC-AUC, false alarm rate, lead time.
Faults: precision, recall, F1, confusion matrix.
RUL: MAE, RMSE, R² and later uncertainty.
System: telemetry-to-dashboard latency, inference latency, CPU/RAM and dropped-message rate.

Synthetic results prove prototype behavior only, not real-engine accuracy.
