# TwinGuard Aero Master UI Specification

`MASTER_UI_REFERENCE.png` is the authoritative visual reference for the Command Center.

The implementation should preserve:
- 216 px white left navigation rail.
- 72 px white top application bar.
- Bright white / pale-blue palette.
- Upper row: large exploded engine hero, UAV System View, AI Decision Center.
- Second row: seven telemetry cards across the left area.
- Right-side Diagnostics / Explainability card spanning the lower dashboard.
- Lower left: Mission Lab.
- Lower center: Mission Replay.
- Thin Simulator strip below Mission Replay.
- Fine borders, subtle shadows, compact engineering typography and generous white space.

Engineering adaptation:
- The reference image contains a turboshaft engine.
- TwinGuard Aero uses a generic UAV opposed aero-piston engine instead.
- The 3D asset is an original visualization and not proprietary DRDO/manufacturer CAD.
