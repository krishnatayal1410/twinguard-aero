# Contributing

Role branches:
- `m1-integration`
- `m2-ai`
- `m3-digital-twin`
- `m4-frontend`
- `m5-backend`

Commit examples:
- `feat(simulator): add lubrication degradation`
- `feat(ai): train anomaly baseline`
- `feat(frontend): add live telemetry cards`
- `fix(backend): validate telemetry payload`
- `docs: update architecture`

Do not commit secrets, `.env`, virtual environments, `node_modules`, generated databases, or proprietary data.
